## Lab 14: Reviewing the Organization Security Overview Dashboard
**Real-World Scenario:** As the administrator responsible for security across your organization, you need to do a realistic weekly review of every open alert, across every repository, in one place.
**Why we are doing this:** The organization-level security overview is the actual daily or weekly starting point for anyone with real security responsibility — this lab practices using it that way.

### Step-by-Step Instructions:
1. **Open Your Organization's Security Tab:** Navigate to your organization's main page, then click `Security`.
2. **Review the Overview:** Note the aggregated summary showing alert counts across Dependabot, secret scanning, and code scanning for every repository.
3. **Filter by Severity:** Use the filter controls to show only `Critical` and `High` severity alerts across the whole organization.
4. **Filter by Alert Type:** Adjust the filter to show only Dependabot alerts, then switch to only secret scanning alerts, noting how the view updates each time.
5. **Filter by Repository:** Narrow the view to just `org-service-lab`, then just `platform-service`, comparing their alert counts.
6. **Review Trend Data:** Look for a chart or graph showing alert volume over time, and note whether it's trending up, down, or flat based on this week's lab activity.
7. **Open a Specific Alert from the Dashboard:** Click directly into one alert from the aggregated view and confirm it takes you to the same detail page you'd reach from that repository's own Security tab.
8. **Check for Team-Based Filtering:** If your organization has teams from Day 2's labs, filter the dashboard by a specific team and note which repositories and alerts are included.
9. **Simulate a Weekly Review:** Write a short one-paragraph summary, as if reporting to a manager, of your organization's current security posture based on what the dashboard shows right now.
10. **Verify:** Confirm you can explain why starting from this dashboard, rather than checking each repository's Security tab individually, is the practical approach once an organization has more than a handful of repositories.
