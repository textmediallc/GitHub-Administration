## Lab 4: Documenting a Project with a Professional README
**Real-World Scenario:** You've just finished the first working version of an internal tool, and your manager has asked you to make it usable by the rest of the team. Right now the repository has no documentation at all.
**Why we are doing this:** A clear README is often the difference between a tool that gets adopted by the team and one that gets abandoned because no one can figure out how to run it.

### Step-by-Step Instructions:
1. **Create a New Repository:**
   * On `github.com`, click the `+` icon and select `New repository`.
   * Name it `readme-practice`, set it to `Public`, and check `Add a README file`.
   * Click `Create repository`.
2. **Open README.md for Editing:** Click on `README.md` in the file list, then click the pencil (edit) icon.
3. **Add a Title and Description:**
   * Write a top-level heading with `#` followed by a project name.
   * Add one or two sentences underneath explaining what the project does and why it exists.
4. **Add an Installation Section:**
   * Add a `## Installation` heading.
   * Add a fenced code block (using triple backticks) with the exact commands needed to install the project.
   * *Explanation:* Installation steps should be copy-pasteable, not paraphrased — someone should be able to follow them without guessing.
5. **Add a Usage Section:**
   * Add a `## Usage` heading with a short example, including at least one inline code reference using single backticks.
6. **Add a Status Table:**
   * Add a `## Status` heading with a Markdown table (using pipes and dashes) listing at least two features and their current status.
7. **Add a Roadmap with a Task List:**
   * Add a `## Roadmap` heading with a task list using `- [ ]` for incomplete items and `- [x]` for at least one completed item.
8. **Preview Your Work:** Click the `Preview` tab above the editor to confirm everything renders as expected before committing.
9. **Commit Your Changes:**
   * Scroll down to the commit panel, write a clear commit message such as "Write initial README", select `Commit directly to the main branch`, and click `Commit changes`.
10. **Verify on GitHub:** Return to the repository's main page and confirm the formatted README now displays on the homepage.
